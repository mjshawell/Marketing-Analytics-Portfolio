# M10 Professional Portfolio

Open M10.Rproj in RStudio. Use Quarto 1.4 or newer. In the Terminal run `quarto render` from the project directory, or use the Build tab. The website output is docs/. This is a starter, not a completed submission.

Replace the profile placeholder with your photo, review biography and project summaries, and add approved aggregate dashboard data or authorized Case 31 data. Never include confidential client records in a public repository. The ignore rules are only a safeguard, not a guarantee of privacy.

Create a GitHub repository, commit the reviewed source and docs output, then configure GitHub Pages to deploy from main /docs. Verify the deployed site. Fill in both real links in submission/M10-submission.qmd and render that file separately (`quarto render submission/M10-submission.qmd`).
